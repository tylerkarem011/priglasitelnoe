# Своё письмо — Romantic Finale

Локальное веб-приложение на FastAPI для создания романтических писем с конвертом, фото, фоновой музыкой и эффектами.

## Возможности
- редактор письма и живое предпросмотрение;
- выбор темы, шрифта и эффекта;
- загрузка одного изображения (до 3 МБ) и аудиотрека (до 5 МБ);
- встроенная синтезированная мелодия без внешнего музыкального файла;
- анимации сердечек, искр, эмодзи и конфетти;
- интерактивный финал с тремя реакциями;
- сохранение писем в SQLite и отдельная ссылка `/l/<id>`;
- `GET /health` для проверки работы сервера.

## Запуск на Mac

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload
```

Откройте http://127.0.0.1:8000.

## Важно

Реакции в интерактивном финале пока отображаются только на устройстве получателя — они не отправляются автору письма. Для обратной связи нужно отдельно добавить серверное сохранение реакций и интерфейс просмотра ответов.

Фото и аудио хранятся в письме как data URL, поэтому не превышайте лимиты загрузки. Перед публичным запуском стоит перейти на PostgreSQL и объектное хранилище для медиа.


## Реакции получателя

После публикации сервер возвращает две ссылки:
- публичную ссылку письма `/l/<id>`;
- приватную ссылку автора `/author/<id>?token=...`.

Сохрани приватную ссылку автора: в ней находится секретный токен для просмотра реакций. Когда получательница выберет одну из реакций, она сохранится в базе данных. Открой приватную ссылку и нажми «Обновить ответы», чтобы посмотреть реакции. Не публикуй и не пересылай приватную ссылку.

Для локального запуска:
```bash
uvicorn app:app --reload
```
Открой `http://127.0.0.1:8000`. Публичные ссылки заработают для других людей после размещения приложения на хостинге.


## Свободный ответ получателя

В опубликованном письме получатель может выбрать одну из реакций или написать собственное сообщение (до 500 символов). Сообщения сохраняются в таблице `reactions` и отображаются на приватной странице автора. Виброотклик вызывается через Web Vibration API там, где браузер и устройство его поддерживают; iOS Safari обычно не предоставляет этот API для обычных веб-страниц.


## Обновления v11

- Имя получателя по умолчанию исправлено на «Елдана».
- Добавлено 8 поводов: свои слова, благодарность, извинение, день рождения, приглашение, скучаю, признание и поддержка.
- Текст основной кнопки и заголовок блока реакции подстраиваются под выбранный повод.
- Открытие письма разделено на этапы: откидывается клапан конверта, исчезает печать, конверт опускается, а лист плавно выдвигается и раскрывается.
- Анимации используют CSS transforms/opacity и отключаются при системной настройке reduced motion.
